# Project Visualisations

This directory contains selected visual evidence from the Financial Market Machine Learning Trading System.

The visualisations highlight key stages of the machine-learning research and evaluation process, including:

- Financial time-series analysis
- Feature engineering
- Model training and evaluation
- Classification performance
- Confusion matrices
- Backtesting results
- Equity curves
- Model comparisons
- Walk-forward validation
- Feature and ablation analysis

Only selected results are included here to provide a concise visual overview of the project.

For the complete implementation and experimental outputs, see the Jupyter Notebook in the `notebooks/` directory.

For the complete academic methodology, evaluation and discussion, see the postgraduate report in the `docs/` directory.

## Important Note

The visualisations represent historical and simulated research experiments.

They do not represent live trading performance or guaranteed future returns.

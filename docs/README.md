# Project Documentation

This directory contains the academic and technical documentation for the Financial Market Machine Learning Trading System.

## Postgraduate Major Project

This project was developed as a postgraduate Computer Science major project investigating the application of machine learning and deep learning to multi-asset financial time-series classification and trading-strategy evaluation.

The research develops and evaluates a machine-learning trading pipeline across multiple financial markets, including:

- Equity indices
- Cryptocurrency
- Gold
- Foreign exchange

The system transforms historical bid/ask OHLC market data into engineered features and sequential model inputs before generating BUY, HOLD and SELL predictions.

## Research Components

The project covers:

- Financial time-series data collection
- Bid/ask data preprocessing
- Mid-price calculation
- Data cleaning and standardisation
- Candlestick feature engineering
- Technical indicators
- Volatility features
- Market-regime analysis
- BUY / HOLD / SELL classification
- Sequential data preparation
- CNN modelling
- LSTM modelling
- MLP modelling
- Random Forest benchmarking
- Ensemble modelling
- Class-imbalance handling
- Backtesting
- Transaction-cost analysis
- Sharpe ratio evaluation
- Maximum drawdown
- Win-rate analysis
- Statistical significance testing
- Ablation and feature-importance analysis
- Walk-forward validation

## Research Objective

The primary objective was to investigate whether machine learning and deep learning models could identify useful patterns in historical financial time-series data and translate predictions into economically meaningful trading signals.

The project evaluates predictive performance alongside financial performance rather than relying on classification accuracy alone.

## Important Notice

This project is an academic and portfolio research project.

The models and backtesting results are not financial advice and the system is not presented as a production or live-trading platform. Historical and simulated performance does not guarantee future results.
